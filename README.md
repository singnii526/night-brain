# 나이트 브레인 (night-brain)

잠이 오지 않는 밤을 위한 **뇌파 · 호흡 · 이완** 도우미. 단일 HTML 파일, 설치·서버·네트워크 없음.

## 실행

`index.html`을 브라우저로 열기만 하면 됩니다. 휴대폰에서는 브라우저 메뉴 → *홈 화면에 추가* 로 앱처럼 쓸 수 있습니다.

> 바이노럴 비트는 **이어폰·헤드폰 필수**. 스피커로 들을 땐 사운드 탭에서 *아이소크로닉*으로 전환하세요.

## 화면

**홈 — 고요한 한 장.** 가운데에는 흑백 월식과 지금 고른 소리(예: *깊은 수면 · 델타 2.5 Hz · 깊은 바람 · 45분 · 이어폰*)만 둡니다. 아래쪽에 조작을 모았습니다.

- **소리 선택 · 호흡 · 몸 이완** — 메뉴의 해당 탭으로 바로 갑니다.
- **큰 버튼** — 소리를 시작합니다. 소리·호흡·이완 중 무엇이든 실행 중이면 같은 자리가 **전체 정지**로 바뀝니다.
- **화면 어둡게** — 검은 레이어로 화면을 덮습니다. 큰 버튼 자리를 누르면 전체 정지, 다른 곳을 누르면 화면만 돌아옵니다. 덮는 동안 아래 버튼은 눌리지 않습니다.
- **메뉴 열기** — 아래에서 올라오는 화면에 기존 5개 탭이 들어 있습니다. 휴대폰 뒤로 가기·Esc로 닫힙니다.

호흡 중에는 홈의 월식이 숨에 맞춰 천천히 커졌다 작아집니다. 호흡과 이완은 음성이 겹치지 않도록 한 번에 하나만 돕니다. 소리는 둘 중 어느 것과도 함께 쓸 수 있습니다.

## 메뉴 탭

| 탭 | 내용 |
|----|------|
| **사운드** | 소리 시작·정지와 남은 시간, 뇌파 프리셋 6종(밤용 4종 + 접어 둔 낮용 베타/감마), 비트·캐리어·볼륨 수동 조절, 배경 소리(브라운/핑크/화이트 + 저역 필터), 하강 모드, 페이드 아웃, 타이머 |
| **호흡** | 4-7-8 · 긴 날숨 4-8 · 박스 4-4-4-4 · 균형 5.5초. 원 애니메이션에 숨을 맞추고 사이클 카운트, 선택적 전환 신호음 |
| **이완** | 점진적 근육 이완(PMR) + 바디 스캔 17단계 유도. **부드러운 음성 안내**(목소리 선택 · 속도 조절)로 눈을 감고 따라갈 수 있음. 4분 36초 / 7분 40초 / 11분 30초 |
| **일지** | 취침·기상 시각, 입면 시간, 야간 각성, 아침 컨디션, 메모 → 7일 막대그래프 + 평균 수면 / 평균 입면 / 수면 효율 |
| **안내** | 사용 순서, 뇌파 대역 설명, 주의사항, 근거가 확실한 수면 위생 |

## 핵심 기능 설명

- **하강 모드** — 타이머 시간에 걸쳐 비트 주파수를 설정값에서 `1.2Hz`까지 선형으로 내립니다. 깨어 있는 상태에서 서파 수면 쪽으로 끌고 가는 방식.
- **페이드 아웃** — 타이머 종료 60초 전부터 소리를 서서히 없앱니다. 갑작스런 정적으로 깨지 않도록.
- **음성 안내** — 눈을 감고 쓰는 앱이라, 이완 단계와 호흡 단계를 기기에 설치된 목소리로 읽어 줍니다. 목소리와 말하기 속도(0.5–1.2×)를 고를 수 있고, 기본값은 0.85× · 피치 0.95로 밤에 덜 날카롭게 맞췄습니다. 한국어 목소리가 없는 기기에는 추가 방법을 안내합니다.
- **스페이스바** — 시작 / 전체 정지.

## 기술

- Web Audio API만 사용. 오디오 파일이 하나도 없습니다.
  - 바이노럴: `ChannelMerger`로 좌/우에 `캐리어 ∓ 비트/2` 사인파를 각각 라우팅
  - 아이소크로닉: 비트 주파수의 LFO로 진폭 변조
  - 배경 소리: `AudioWorklet`이 오디오 스레드에서 샘플을 계속 새로 만들어 **반복이 전혀 없음**(예전 6초 버퍼 루프는 5.95초마다 같은 소리가 되풀이되고 이음새에서 음량이 꺼져 뚝뚝 끊기게 들렸음). 모듈은 `data:` URL로 올려 파일로 직접 열어도 동작. AudioWorklet이 없는 브라우저는 30초 버퍼 + 1.5초 등전력 크로스페이드로 폴백. 핑크는 Paul Kellet 필터, 브라운은 적분 근사
  - 페이드 아웃은 오디오 시계에 예약 — 화면이 꺼져 타이머가 늦어져도 제때 줄어듦
- 음성은 Web Speech API(`SpeechSynthesis`)로 기기에 설치된 목소리를 사용. 음성 파일도, TTS 서버 호출도 없습니다.
- 설정(`nb_set`)과 수면 일지(`nb_log`)는 `localStorage`에만 저장. 서버로 전송하지 않습니다.
- 외부 라이브러리·폰트·CDN 없음.

## 주의

의학적 치료가 아닙니다. 3개월 이상 불면이 이어지면 수면 클리닉의 인지행동치료(CBT-I)를 권합니다.
**뇌전증·발작 이력**이 있으면 리듬 자극(특히 아이소크로닉)을 피하고 의사와 상의하세요. 자세한 내용은 앱의 *안내* 탭 참고.
