# 나이트 브레인 (night-brain)

잠이 오지 않는 밤을 위한 **뇌파 · 호흡 · 이완** 도우미. 단일 HTML 파일, 설치·서버·네트워크 없음.

## 실행

`index.html`을 브라우저로 열기만 하면 됩니다. 휴대폰에서는 브라우저 메뉴 → *홈 화면에 추가* 로 앱처럼 쓸 수 있습니다.

> 바이노럴 비트는 **이어폰·헤드폰 필수**. 스피커로 들을 땐 사운드 탭에서 *아이소크로닉*으로 전환하세요.

## 구성

| 탭 | 내용 |
|----|------|
| **사운드** | 뇌파 프리셋 6종(델타/세타/알파/SMR/베타/감마), 비트·캐리어·볼륨 수동 조절, 배경 소리(브라운/핑크/화이트 + 저역 필터), 하강 모드, 페이드 아웃, 타이머 |
| **호흡** | 4-7-8 · 긴 날숨 4-8 · 박스 4-4-4-4 · 균형 5.5초. 원 애니메이션에 숨을 맞추고 사이클 카운트, 선택적 전환 신호음 |
| **이완** | 점진적 근육 이완(PMR) + 바디 스캔 17단계 음성 없는 텍스트 유도. 7 / 12 / 18분 |
| **일지** | 취침·기상 시각, 입면 시간, 야간 각성, 아침 컨디션, 메모 → 7일 막대그래프 + 평균 수면 / 평균 입면 / 수면 효율 |
| **안내** | 사용 순서, 뇌파 대역 설명, 주의사항, 근거가 확실한 수면 위생 |

## 핵심 기능 설명

- **하강 모드** — 타이머 시간에 걸쳐 비트 주파수를 설정값에서 `1.2Hz`까지 선형으로 내립니다. 깨어 있는 상태에서 서파 수면 쪽으로 끌고 가는 방식.
- **페이드 아웃** — 타이머 종료 60초 전부터 소리를 서서히 없앱니다. 갑작스런 정적으로 깨지 않도록.
- **화면 어둡게(🌙)** — 화면을 거의 검게 만듭니다. 아무 곳이나 탭하면 복귀.
- **스페이스바** — 재생 / 정지.

## 기술

- Web Audio API만 사용. 오디오 파일이 하나도 없습니다.
  - 바이노럴: `ChannelMerger`로 좌/우에 `캐리어 ∓ 비트/2` 사인파를 각각 라우팅
  - 아이소크로닉: 비트 주파수의 LFO로 진폭 변조
  - 배경 소리: 6초 노이즈 버퍼를 생성해 루프. 이음새 50ms 크로스페이드로 딸깍 소리 제거. 핑크는 Paul Kellet 필터, 브라운은 적분 근사
- 설정(`nb_set`)과 수면 일지(`nb_log`)는 `localStorage`에만 저장. 서버로 전송하지 않습니다.
- 외부 라이브러리·폰트·CDN 없음.

## 주의

의학적 치료가 아닙니다. 3개월 이상 불면이 이어지면 수면 클리닉의 인지행동치료(CBT-I)를 권합니다.
**뇌전증·발작 이력**이 있으면 리듬 자극(특히 아이소크로닉)을 피하고 의사와 상의하세요. 자세한 내용은 앱의 *안내* 탭 참고.
