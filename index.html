기록

어떻게 쓰면 좋은가

  1. 불을 끄고 침대에 누운 뒤 시작합니다. 앉아서 들으면 효과가 반으로 줄어듭니다.
  2. 호흡 탭에서 4-7-8 호흡을 4~6회. 여기서 이미 졸리면 그대로 잠드세요.
  3. 사운드 탭에서 잠들기 또는 깊은 수면 프리셋 + 하강 모드 + 45분 타이머.
  4. 생각이 계속 돌면 이완 탭의 바디 스캔으로 주의를 몸으로 옮깁니다.
  5. 화면은 🌙 버튼으로 거의 검게 만들 수 있습니다. 아무 곳이나 누르면 돌아옵니다.

뇌파 대역이 뜻하는 것

  • 델타 0.5–4Hz — 깊은 서파 수면. 몸의 회복이 일어나는 구간.
  • 세타 4–8Hz — 잠으로 넘어가는 문턱, 얕은 수면과 몽롱함.
  • 알파 8–12Hz — 눈을 감고 편안히 쉬는 상태. 긴장 풀기용.
  • SMR 12–15Hz — 차분하지만 깨어 있음. 머릿속 잡음이 심할 때.
  • 베타 15–30Hz — 각성과 사고. 낮에 졸릴 때만.
  • 감마 ~40Hz — 몰입과 주의 집중.

바이노럴 vs 아이소크로닉

바이노럴 비트는 좌우 귀에 살짝 다른 주파수를 넣어(예: 108.75Hz / 111.25Hz) 뇌가 그 차이인 2.5Hz를 스스로 만들어내게 하는 방식입니다. 반드시 이어폰이 필요합니다.

아이소크로닉 톤은 하나의 소리를 리듬에 맞춰 끊어 주는 방식이라 스피커로도 됩니다.

꼭 읽어주세요

  • 이 앱은 의학적 치료가 아닙니다. 3개월 이상 불면이 이어지거나 낮 생활이 힘들면 수면 클리닉의 인지행동치료(CBT-I)가 훨씬 효과적입니다.
  • 뇌전증·발작 이력이 있거나 심박 조절기를 쓰는 경우, 리듬 자극(특히 아이소크로닉)은 피하고 의사와 먼저 상의하세요.
  • 볼륨은 말소리보다 작게. 밤새 큰 소리로 들으면 청력에 좋지 않습니다.
  • 운전 중이나 주의가 필요한 일을 할 때는 사용하지 마세요.
  • 뇌파 동조(brainwave entrainment)의 수면 효과는 아직 연구가 진행 중이며 사람마다 차이가 큽니다. 효과가 없다면 호흡·이완·수면 위생 쪽이 근거가 더 확실합니다.

근거가 확실한 것들

  • 매일 같은 시각에 일어나기 — 취침 시각보다 이게 먼저입니다.
  • 침대는 잠 외에 쓰지 않기. 20분 이상 안 오면 일어나서 어두운 곳에 있다가 졸릴 때 다시 눕기.
  • 카페인은 취침 8시간 전까지. 술은 잠을 얕게 만듭니다.
  • 기상 후 아침 햇빛 10분이 그날 밤의 멜라토닌 시각을 정합니다.
  • 침실은 어둡고 시원하게 (18–20℃).
